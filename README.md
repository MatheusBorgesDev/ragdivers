# RAGDivers

**Answers that know which patch they're from.** — an unofficial Helldivers 2 companion.

RAGDivers answers players' questions about the Helldivers 2 galactic war, weapons, enemies and patches. It cites the
source of every claim, says which patch the information is from, and says "I don't know" when the sources do not
cover the question.

> RAGDivers is an unofficial fan project, not affiliated with or endorsed by Arrowhead Game Studios or Sony
> Interactive Entertainment.

**Status:** Phase 0, in progress. The design is in [`docs/SPEC.md`](docs/SPEC.md) (in Portuguese).
